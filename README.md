# Tieba Neat · 贴吧清爽宽屏

用于新版百度贴吧的油猴脚本，改善桌面宽屏阅读，减少广告、推荐栏目和推广入口的干扰。

## 功能

- 首页、吧页、帖子详情页和个人主页的宽屏适配，四类页面共用同一正文列宽和水平框架；宽屏时正文以整个视口为轴心居中，窄屏放不下时回到左侧导航右侧居中。
- 正文列默认加宽到 `1320px`，在宽屏上利用两侧空间；窗口变窄时按可用宽度统一收缩。
- 顶部换用不带文字的贴吧图标，搜索栏加宽到最多 `800px`（窄窗口按 `55vw` 收缩），宽屏时与正文框架中心对齐。
- 正文框架左右留白收紧到 `16–24px`，滚动条贴近正文，不再远离内容。
- 默认收起首页、吧页、个人主页和帖子页的右侧栏；设置中合并为一个“右侧栏”总开关。
- 吧页返回按钮收进左侧留白，不再压住内容；没有可返回的贴吧历史时回到贴吧首页。
- 可设置页面、正文以及图片和视频的最大宽度，窗口变窄时正文统一收缩；重新打开右侧栏时，侧栏放不下会移到正文下方，宽度统一为 332px。
- 屏蔽“最有料”、相关推荐、广告、App 下载引导和游戏等推广图标，保留消息入口。
- 右侧栏、广告、顶部推广、个人主页推广和左侧导航可独立开关，支持按栏目标题或自定义 CSS 选择器屏蔽，也可直接点选元素。

## 安装与使用

1. 在浏览器的油猴脚本管理器中新建脚本，粘贴根目录 `tieba-neat.user.js` 的完整内容并保存。
2. 打开或刷新 `tieba.baidu.com` 页面。
3. 从脚本管理器菜单打开“设置”“点选屏蔽元素”或“显示 / 隐藏被屏蔽的元素”。

默认页面最大宽度为 `2560px`，正文列为 `1320px`，媒体为 `820px`。设置中可填写 `px`、`vw` 或 `%`，保存后生效。更新脚本后刷新页面。

```text

├── README.md
└── .gitignore
```

主脚本不需要构建，也没有第三方依赖。仓库当前不包含离线测试、页面快照、脱敏工具或测试产物。

## 隐私

- 布局验证只使用公开页面，不读取、保存或提交带登录态、账号、私信、关注列表等私人内容的页面。
- 不保存页面截图，不把截图或单张保存的 HTML 作为布局验证的唯一依据。
- 不将原始页面、登录态数据或带个人参数的链接发送给网络工具、远程服务或其他外部应用。
- 如果以后需要重新保存页面快照，必须先在本地完成脱敏并验证；原始 HTML 只能由本地工具处理，不得直接读入 AI 上下文。

## 验证

在真实浏览器中打开公开的贴吧页面，加载完成后注入当前脚本，直接测量 DOM 尺寸、可见性和点击结果。覆盖首页、吧页、帖子页、个人主页，以及 `2560`、`1920`、`1366`、`1006`、`768` 窗口；重点检查正文宽度、框架居中、搜索栏对齐、滚动条位置、侧栏开关、返回按钮、设置恢复和旧配置迁移。

真实站点注入前需要先补齐 `GM_getValue`、`GM_setValue`、`GM_registerMenuCommand` 的 shim；部分浏览器工具的初始化脚本对真实站点不生效，必须在页面加载后手动注入。

主脚本语法检查：

```powershell
node --check tieba-neat.user.js
```

当前没有离线自动化回归，验证结果以真实浏览器实测为准。
