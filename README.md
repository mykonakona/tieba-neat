# 贴吧清爽宽屏 Tieba Neat

## 简介

只适用于**新版百度贴吧桌面布局**。旧版页面的结构和类名不同，脚本不会生效。

## 使用

[![安装](https://img.shields.io/badge/%E5%AE%89%E8%A3%85%E8%84%9A%E6%9C%AC-Tampermonkey%20%2F%20Violentmonkey-2ea44f?style=for-the-badge)](https://raw.githubusercontent.com/mykonakona/tieba-neat/main/tieba-neat.user.js)

使用前请确认浏览器已安装 [Tampermonkey](https://www.tampermonkey.net/) 或 [Violentmonkey](https://violentmonkey.github.io/) 扩展。

## 功能

- 首页、吧页、帖子页、个人主页统一宽屏：正文加宽并以视口为中心，窄屏自动回退，不压住左侧导航。
- 收起左侧导航栏时，正文及时回到视口中央，不会停留在偏右位置；展开后恢复原状。
- 顶部搜索框与正文中心对齐；吧头、个人主页头部跟随正文列。
- 页面背景统一（顶部栏、侧栏、卡片、正文、两侧留白等），可选白色、灰色、米色、黑色或 `auto`，也可直接填颜色代码，填了就以它为准。
- 背景为深色时文字自动变浅，浅色时文字变深。
- 返回 / 回到顶部按钮收进正文左侧留白，约 `36–40px`；平时透明，悬停显示圆形底色。
- 首页回到顶部固定在正文左下角；帖子页底部“想说点啥”与正文同宽。
- 屏蔽右侧栏、广告、下载引导、顶部推广（保留消息）、个人主页“常用功能”和“最有料”“相关推荐”等推荐栏目。
- 首页帖子列表可切换“关注 + 推荐 / 只看关注 / 只看推荐”；单独查看某类时会自动补载，避免只剩一条；连续补载仍无对应内容时停止请求并显示提示。
- 设置中保留“屏蔽左侧导航栏”和“帖子列表”显示开关。

## 设置

从脚本管理器菜单打开“设置”，可调整：

- 宽屏开关。
- 页面、正文列、图片 / 视频的最大宽度。
- 背景开关、预设颜色、颜色代码。
- 是否屏蔽左侧导航栏。
- 首页帖子列表显示内容：关注 + 推荐、只看关注、只看推荐。
- 恢复默认。

## 开发与测试

主脚本 `tieba-neat.user.js` 仍为单文件，直接安装即可运行，不需要构建或任何运行时依赖。

`tests/` 下的离线回归测试只依赖开发期的 `jsdom`，用合成的页面夹具覆盖：

- 推荐栏目标题识别：站点复用同一文本节点改写标题、标题改回普通栏目后恢复、标题元素被替换、标题元素自身就是被隐藏区块、`<img alt/title>` 作为标题，以及一个区块含多个关键词标题时只在全部不再命中后才恢复；均不误伤正文、评论、简介。若 `alt/title` 变化事先未等到页面静止，仍应自动调度（测试先等 idle 再改属性，不手动 `flush()`/resize）。
- 受保护的用户内容命中关键词时既不隐藏、也不安排布局重算（避免纯 timer 自循环）。
- 首页关注 / 推荐自动补载、停止阈值与空提示、切回“关注 + 推荐”恢复列表并取消重试。
- SPA 历史前进 / 后退时的返回按钮判定，并确认不改写站点 `history.state`。
- 正文视频与图片按“图片 / 视频最大宽度”限宽（含改值与恢复），播放器包裹层仍保持视频比例。
- 左导航收起 / 展开后补一次最终布局重算（站点只改后代 class 并播放 CSS 过渡），且不产生观察器自触发循环。

断言“无自循环”的方式：拦截 `setTimeout` 统计调度次数，要求两个连续的静默窗口计数不再增长，而不只是看 mutation 次数。

```powershell
npm install      # 仅安装测试依赖
npm test         # 离线回归测试
npm run check    # 主脚本语法检查
```

`jsdom` 没有布局引擎，尺寸类断言只能锁定生成的 CSS 规则与重算时机；真实宽度、对齐与比例需在真实贴吧复核。

真实贴吧的 DOM 与后端行为仍以线上复核为准；离线测试不替代真实页面验证。
